# 📊 複数Excelファイル統合ツール
(Excel Merge Tool)

実務効率化のための、複数Excelファイル統合Pythonツールです。  
月別の売上データや、複数店舗の在庫リストを1つのファイルにまとめる作業を自動化します。

## ✨ 特徴

- ✅ フォルダ内の全Excelファイルを自動検出
- ✅ データの引用元（ファイル名）を自動記録
- ✅ エラーハンドリング付き
- ✅ ファイル名（1月、2月…）の昇順ソートに対応。

## 🎯 活用シーン
- **月別売上データの統合**: 12ヶ月分のファイルを1つの年間データに
- **複数モールの在庫統合**: 楽天・Amazon・Yahoo!などのデータを集約
- **支店別レポートの集計**: 各拠点から送られてくる報告書を一括でまとめる

## 🚀 使い方

### 1. セットアップ（初回のみ）
ターミナルでプロジェクトのフォルダに移動し、以下のコマンドで必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

### 2. 準備
統合したいExcelファイルを sample_data フォルダに入れます。

### 3. 実行
以下のコマンドで統合を開始します。
```bash
python merge_excel.py
```

### 4. 結果の確認
output フォルダ内に、日付付きの**「統合結果Excelデータ」**が保存されます。

## 💡 カスタマイズ方法

### 異なるフォルダを指定する場合
```python
input_folder = "あなたのフォルダパス"
output_file = "出力ファイル名.xlsx"
merge_excel_files(input_folder, output_file)
```

## 📝 注意事項

- 列名の統一: 統合するファイル同士で、項目名（列名）を揃えておいてください。
- ファイル形式: .xlsx 形式のファイルに対応しています。
- 上書き防止: 実行ごとに新しいファイル名で保存されるため、元のデータを上書きせず、別名で保存し　ます。
